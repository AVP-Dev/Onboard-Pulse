## 2. Критические дефекты и подтверждение их устранения

1. **`Стаж адаптации:  дней` в карточке проблемы:**
   - *Причина:* в `getIssueById` репозитория поле `days_in_company` не вычислялось для вложенного объекта `employee`.
   - *Решение:* добавлен автоматический расчёт разницы между текущей датой и `hire_date`.
2. **Мобильная верстка анкеты (`390px`):**
   - *Причина:* отсутствие `w-full` в контейнере `page.tsx` и `min-width: auto` у кнопок CSS Grid.
   - *Решение:* добавлен экспорт `viewport` в `layout.tsx`, `overflow-x-hidden`, `min-w-0` для кнопок, проверен скриншот.
3. **Утечка HR-меню в анкету сотрудника:**
   - *Причина:* единый глобальный навбар рендерился на всех маршрутах.
   - *Решение:* компонент `Navbar` определяет `isSurvey` и рендерит изолированную чистую мобильную шапку без HR-ссылок.
4. **Отсутствие авторизации на API:**
   - *Причина:* открытые POST-эндпоинты.
   - *Решение:* реализован `enforceAdmin` в `src/lib/auth.ts`, проверяющий права HR и отклоняющий неавторизованные запросы с 403 кодом.
5. **Хаос в списке проблем на главной:**
   - *Причина:* все тикеты выводились единым списком.
   - *Решение:* внедрены SaaS-вкладки статусов (Все, Критические, Внимания, Новые, В работе, Ожидают проверки, Решённые) и два режима отображения (Таблица / Карточки).
