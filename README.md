# Onboard Pulse 🚀

Система оперативного мониторинга адаптации новых сотрудников (склад, розничная сеть, отдел продаж, офис).
Контрольный цикл первых 90 дней: сбор регулярного пульса по 5 факторам, детерминированная детекция сигналов внимания и критических проблем, назначение корректирующих мер и верифицированное закрытие **строго после подтверждения сотрудником**.

---

## 🐳 Запуск в Docker

```bash
# 1. Сборка и запуск контейнера в фоне
docker compose up --build -d

# 2. Остановка
docker compose down
```
- Приложение доступно: **http://localhost:3088** (или заданный $HOST_PORT)
- База данных SQLite сохраняется в volume `pulse-data`. При первом старте демонстрационные данные инициализируются автоматически.

---

## ⚡ Локальный запуск (без Docker)

**Требования:** Node.js >= 22.5.0 (рекомендуется Node.js 24 или 26 LTS).

```bash
# 1. Установка зависимостей
npm install

# 2. Инициализация демо-базы
npm run db:seed

# 3. Запуск dev-сервера
npm run dev

# Либо production-сборка и запуск:
npm run build && npm run start
```

## 🧭 Навигация по разделам

- **`/` (Обзор адаптации):** единый интерактивный пульт — 4 карточки метрик переключают рабочую область на «Проблемы» или «Сотрудники», виджет контрольных точек.
- **`/employees` (Сотрудники):** реестр новичков с фильтрацией по отделам и прогресс-барами стажа (0–90 дней).
- **`/employees/[id]` (Карточка сотрудника):** 90-дневный график срезов (дни 3, 7, 14, 30, 60, 90), кнопка «Напомнить», журнал заметок HR в SQLite с подсветкой Highlights.
- **`/questions` (Банк вопросов):** 22 дифференцированных вопроса с фильтрацией по рубежам, 5 шкалам и специфике отделов.
- **`/issues` (Очередь проблем):** реестр инцидентов с воронкой статусов и назначением ответственных.
- **`/issues/[id]` (Карточка проблемы):** жизненный цикл (NEW -> IN_PROGRESS -> PENDING_VERIFICATION -> CLOSED).
- **`/analytics` (Аналитика):** сводные показатели по 4 подразделениям и 5 категориям адаптации.
- **`/survey/[token]` (Анкета новичка):** mobile-first форма пульс-опроса по одноразовой защищённой ссылке.

## 🛠 Технологический стек

- **Среда и язык:** Node.js v26.4.0 LTS / TypeScript 5.7+
- **Фреймворк:** Next.js 16+ (App Router, Server Components & Route Handlers), React 19
- **Стилизация:** Tailwind CSS v3 (семантические токены, Zero Hardcoded Colors)
- **База данных:** SQLite через стандартную библиотеку `node:sqlite` (`DatabaseSync`, транзакции ACID)
- **Контейнеризация:** Docker (multi-stage build на `node:22-alpine`) + Docker Compose
- **Безопасность:** Одноразовые UUIDv4 токены, fail-closed валидация, синтетические профили без реальных ПДн
